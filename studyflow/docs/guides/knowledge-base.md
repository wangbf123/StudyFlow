# 资料工作台使用指南

这是原有资料处理与检索工作台的说明，可从个人知识工作区进入，也可通过 `/#classic` 打开。Markdown 笔记、双向链接与图谱见 [个人知识工作区](personal-workspace.md)。

## 1. 建立自己的知识空间

创建知识库名称和描述，按课程、研究方向或项目分别积累资料。当前权限单位为用户所属知识库；组织共享、协作编辑和细粒度角色尚未实现。

概览显示当前库的文档数量、有效知识分片、已保存的当前版本原文引用和向量覆盖率。统计来自 MySQL 的真实聚合，不使用演示常量。文档处理过程中，最近任务视图自动刷新。

## 2. 上传、筛选和重建资料

支持 PDF、TXT、Markdown、JPG、JPEG、PNG 和 WebP。文本 PDF 使用 PDFBox，扫描 PDF / 图片需要 PaddleOCR 服务。普通上传限制由 Spring multipart 配置控制；分片上传另有合并路径和大小校验。

上传后主流水线按 `PARSE → EMBED → INDEX` 推进。INDEX 完成后资料可检索，并异步生成摘要。摘要模型超时或失败时，主索引仍然保持就绪。摘要输入有字符上限；截断时资料列表显示“基于前 N 字符”，不冒充全文摘要。

资料列表支持文件名及状态筛选，采用 ID 游标加载更多。文档重建会创建新 generation；重建期间旧版本隐藏，之前的问答引用标记为历史版本。删除先写 tombstone，再异步清理分片和索引。共享原始对象的引用计数和定期物理回收仍待实现。

## 3. 检索自己的知识

| 模式 | 适用问题 | 行为 |
|---|---|---|
| 关键词 BM25 | 专有术语、具体名词、错误码 | ES 文本检索 |
| 语义 VECTOR | 同义表达、自然语言问题 | BGE 查询向量及 ES HNSW |
| 混合 RRF | 同时需要术语与语义覆盖 | 合并两路原始排名 |

检索工作台展示原文片段、来源、关键词/语义排名及排序依据。分数是排序信号，不是准确率或置信度。默认 mock embedding 仅用于开发链路，会明确标记；真实语义检索请启动固定版本的 BGE 侧车。

混合模式在 embedding 不可用时退化为关键词检索，并显示降级提示；VECTOR 单独模式没有可用向量时返回错误。ES 自身故障不会被伪装成空结果。查询后复查文档归属、可检索状态、generation 和正文内容，避免返回旧投影。

## 4. 提问并核对原文

问答返回结构化结论及引用按钮。打开引用后可以看到页码/片段、连续原文引文和高亮位置。生成内容需要经过严格 JSON、来源白名单、原文匹配、权限与版本检查；真实模型模式额外执行独立核验请求。

默认 mock 只摘录原文，显示 `EXTRACTIVE_ONLY`。这条路径可以验证引用和持久化，不能用来判断真实模型幻觉率。真实核验器仍可能误判；重要结论应阅读原文确认。

SSE 在核验前只展示状态，核验及保存完成后发送答案。连接意外结束会报错，并提示检查历史记录；切换知识库或离开页面会取消当前流读取。

## 5. 学习 Agent

知识助手使用当前的持久化 Harness，支持笔记、图谱、文档检索和领域子任务；成果发布复用问答的原文匹配、权限和版本复核。默认 Mock 只验证摘录闭环，不能代表真实模型准确率。详见 [Agent 设计](../LEARNING_AGENT.md) 和 [四层十二模块架构](../agent/harness-architecture.md)。
