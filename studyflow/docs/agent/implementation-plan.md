# StudyFlow：可扩展知识库 + Agent

更新：2026-10-31。本分支包含个人知识工作区与四层十二模块 Agent 的完整实现。

以个人为中心，用户自由创建领域知识库、调整层级、组织笔记与资料。笔记是内容入口，双向链接形成图谱；Agent 在选定的知识库范围内使用笔记、图谱和原始资料，产出带证据的成果，再保存回知识库。

## 本轮 Harness 架构升级

具体边界、技术版本和启用方法见 [四层十二模块架构](harness-architecture.md)。原有知识工作区继续保留；本轮增加模型网关、五种 Skill、Token 预算与结果压缩、分类型记忆、MCP 客户端、可选容器执行、持久化领域子任务与共享预算、运行评估和调用观测。

## 数据与边界

个人 → 任意知识库树 → 笔记 / 项目记录 / 决策 / 资料 / 成果。父子目录用于组织；授权与任务选定范围独立检查。

跨知识库通过明确链接与引用建立联系。图谱不引入访问权限；跨域任务最多选择 8 个知识库。当前版本是单账号私有知识空间，不包含团队共享 ACL。

笔记正文、版本、链接、任务状态和报告保存在 MySQL。Elasticsearch 继续承担原始文档的 BM25 / 向量 / RRF 检索。Neo4j 是可重建的图关系投影，不能独立决定权限或事实。

## 复用策略

- 复用现有文档解析、BGE、Elasticsearch、RRF、原文核验、Redis 会话和监控。
- LangGraph4j 负责图拓扑、条件路由和 checkpoint resume；领域事务保存提交状态、事件和报告，保证租约 fencing 与业务事务边界。
- CodeMirror 6 提供编辑、历史、快捷键与 Markdown 语法；G6 提供布局、画布、缩放和节点交互；DOMPurify 处理 Markdown 预览输出。
- Neo4j 官方 Java Driver 提供连接池、受控查询和可重试事务。
- 上下文按 Token 装配与压缩，工具结果持久化并按需读取，历史与长期记忆限定范围。未直接嵌入 context-mode、claude-mem 或其他 Coding Agent 插件。

## 当前能力的准确范围

1. 图谱表达显式 Wiki 链接、知识库层级和引用关系。自动实体抽取、推测关系审核、完整 GraphRAG 召回排序属于后续扩展。
2. 笔记搜索目前是标题与正文的有界文本搜索；原始文档继续使用现有混合检索。
3. 五个 Skill 共用图执行流程，以任务指令与交付要求配置；尚无用户编写执行脚本或远程插件市场。
4. 长期资产包括笔记、报告、决策与项目记录；跨会话记忆保存偏好、有来源的知识/方法与任务经历，按范围、版本和有效期过滤。尚未加入自动用户画像、向量记忆索引或经验压缩模型。
5. Mock 模式完成真实工具与数据库调用，生成可核验原文摘录。语义研究质量需要另配真实模型评估。
6. 当前默认深色桌面工作区，提供移动布局；浅色主题、任意拖拽分屏、整库附件导入导出仍可继续完善。
