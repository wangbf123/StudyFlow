# StudyFlow Web

StudyFlow Web 是 StudyFlow 后端的轻量演示端，用于展示知识库管理、文档上传、全文搜索、RAG 问答和引用来源。

## 启动

```powershell
cd "C:\Users\29272\Documents\New project\studyflow-web"
npm.cmd install --cache .\.npm-cache
npm.cmd run dev
```

访问：

```text
http://localhost:5173
```

后端默认地址：

```text
http://localhost:8080
```

## 页面能力

```text
登录 / 注册
知识库创建与切换
资料上传与解析状态展示
知识库全文搜索
RAG 召回调试
普通问答
流式问答
问答历史
引用来源原文查看
```
